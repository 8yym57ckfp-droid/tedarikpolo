# SafePays v166.16

- Team profile is now restricted to password change and 2FA controls.
- Team users cannot edit email, name, or role from their profile.
- `SafeAdmin.updateSelf()` ignores profile identity/email changes for team accounts and only persists password/2FA fields.
- Per-team self active/passive control is available in the header on every team/admin page beside the theme switch, unless Owner disables that control for the team.
- Self-reactivation remains separately controlled by Owner.
- Team self-status changes are persisted through the existing admin store.
