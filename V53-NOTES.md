# Safepays v53
- Added persistent member-side interface translation engine.
- Existing 68-language selector remains available with flags.
- Main member UI is translated for Turkish, English, German, French, Spanish, Italian, Portuguese, Russian, Arabic, Chinese, Japanese, Korean and Hindi.
- Unsupported selected languages gracefully fall back to English while retaining the selected language/flag.
- Language preference persists in localStorage across member pages.
- RTL layout is enabled for Arabic/Persian/Hebrew/Urdu language selections.
